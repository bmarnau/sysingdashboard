# L2 Cockpit P3 Read-only Route Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die schreibgeschützte Route `/managementcockpit` auf Basis des bestehenden P2-Serververtrags bereitstellen.

**Architecture:** Die Route ruft ausschließlich `readManagementCockpitFn({ data: {} })` auf. Ein gemeinsamer Permission-Gate erlaubt Projektmanager, Teamlead, Administrator und Systemadministrator über die bestehenden Management-Permissions; alle anderen Rollen laden keine Cockpitdaten. Eine reine Präsentationskomponente stellt Handlungsbedarf vor Kennzahlen, Datenzustände und bestehende Drill-down-Ziele dar.

**Tech Stack:** React 19, TanStack Router/Start, TypeScript, Testing Library, Vitest, Tailwind.

**Spec:** `docs/L2-COCKPIT-SCHNITT-KONZEPT.md` L2-03, L2-05 bis L2-09 und `docs/BSF-07-MANAGEMENT-COCKPIT-DESIGN.md` §§5, 7, 14.
